# Qwen 语音

用阿里云百炼（通义）把文字读出来，可以挑选音色，也能用一段录音复刻声音。

## 开始使用

1. 在插件中心安装「Qwen 语音」，再到插件页的「已安装」里打开它的开关，马上就能用，不用重启。
2. 打开本插件详情的「设置」，添加一个 Qwen 语音账号，填写 API Key 和服务地址。
3. 保存后，在应用「设置 → 语音」（手机上是「我的 → 语音」）中选择账号、模型和音色。不同模型能用的音色不一样；用自定义模型时，可以手动填写音色 ID。

可以添加多个账号，各自保存自己的设置。配好后可以先试听一段文字，确认账号能用；试听不会改掉你选好的默认语音。

## 复刻声音

1. 先在「设置 → 资源存储」（手机上是「我的 → 图片与附件」）里选好一个上传插件（比如 S3 或阿里云 OSS 资源上传）。录音要先传到网上，百炼才能读取，所以「保存在本地」这种方式用不了。
2. 准备一段清晰的录音，WAV、MP3 或 M4A 格式，不超过 10 MB。
3. 复刻完成后，新音色可能要等一会儿才能用，刷新音色列表再选。

上传的录音不会被自动删除，也不会改动你存储的访问权限。

## 常见问题

**取消了还会扣费吗？** 可能会。取消只是不再等待结果，百炼那边已经完成的操作仍可能计费。

## 小提醒

- 电脑上需要 Tau 0.60.2 或更高版本，手机上需要 0.2.9 或更高版本。
- 合成语音和复刻声音都可能产生百炼的费用。
- API Key 不要发给别人，也不要贴在截图或问题描述里。
