# Qwen 语音

提供阿里云百炼语音合成、音色查询和声音复刻。可在语音设置中配置多个独立账号，选择各自的模型和音色。

安装启用后，在「设置 → 语音 → 语音合成」添加Qwen语音账号，填写API Key及服务地址，保存后选择模型和音色。系统音色与模型版本关联，自定义模型可以手工填写音色ID。

声音复刻使用一个参考音频，先经「资源存储」选定的上传插件上传为公开地址，再提交百炼；本地保存模式无法提供公网地址。音频应为WAV、MP3或M4A，当前插件沿用10MB限制。创建后服务端可能仍在部署，刷新音色列表后再选用。不会自动更改桶权限，不会删除远端参考文件。

合成及复刻可能产生服务商费用；取消不代表撤回已完成的服务端操作。插件采用MIT许可。
