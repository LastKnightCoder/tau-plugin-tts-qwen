# Qwen 語音

使用阿里雲百煉（通義）進行語音合成、朗讀文字，可挑選音色，也能上傳一段錄音複刻聲音。

## 開始使用

1. 在外掛中心安裝「Qwen 語音」，再到外掛頁的「已安裝」中開啟開關，立即生效，無需重新啟動。
2. 開啟本外掛詳情的「設定」，新增一個 Qwen 語音帳號，填寫 API Key 與服務位址。
3. 儲存後，在應用程式「設定 → 語音」（手機為「我的 → 語音」）中選擇帳號、模型與音色。不同模型支援的音色不同；使用自訂模型時，可手動填寫音色 ID。

可新增多個帳號，各自保存獨立設定。設定完成後可先試聽一段文字確認帳號可用；試聽不會改變你選好的預設語音。

## 複刻聲音

1. 請先在「設定 → 資源儲存」（手機為「我的 → 圖片與附件」）中選好一個上傳外掛（例如 S3 或阿里雲 OSS 資源上傳）。錄音必須先上傳至網路，百煉才能讀取，因此無法使用「儲存在本機」。
2. 準備一段清晰的錄音，格式為 WAV、MP3 或 M4A，檔案大小不超過 10 MB。
3. 複刻完成後，新音色可能需要稍候片刻才能使用，請重新整理音色清單後再選取。

上傳的錄音不會自動刪除，也不會變更你儲存空間的存取權限。

## 常見問題

**取消後還會扣費嗎？** 可能會。取消只是不再等待結果，百煉端已經完成的操作仍可能計費。

## 小提醒

- 語音合成與複刻聲音都可能產生百煉費用。
- 請妥善保管 API Key 金鑰，切勿傳給他人，也不要貼在截圖或問題描述中。
